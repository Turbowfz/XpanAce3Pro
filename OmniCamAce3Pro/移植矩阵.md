# OmniCam-Muse → Ace 3Pro 功能适配矩阵

判定基准：**本机相机 6.020.876 反编译（XpanPort/11_反编译）+ 本机 odm 提取（02_本机提取、12_验证/_证据/odm）**。
每个"不适用"结论都附证据路径；手机回来后可复核。

## A 层·数据挂载（KSU bind-mount）

### ★ "补全"可行性判定（2026-10-31，目录级 diff + 反编译读路径核对）
Muse payload（X9U，542 文件）vs 本机 odm（6.020.876，787 文件）目录级 diff：
| Muse 目录 | 文件数 | 本机 odm | 本机相机读路径（11_反编译检索） | 判定 |
|---|---|---|---|---|
| master_color | 342 | **无此目录** | 仅统计埋点引用（EventKeys/EventPortraitInCapture），无实际读取 | ❌ 挂了也没人读 |
| gr_adjustment_lmt | 36 | 无此目录 | **0 引用**（GR 模式不存在） | ❌ |
| watermark_drawables / pld_watermark / watermark_master_styles | 35 | 无此目录 | **0 引用**（7.x 水印体系） | ❌ |
| x10_basictone | 35 | 无此目录 | 需 X10 unit.sdk jar（本机 unit.sdk 无对应类） | ❌ |
| meishe_lut | 42 | 有（120 文件） | 原生 Meishe SDK 读（Java 无字符串，目录存在即在读） | ⏳ 唯一可试：X9U 集里若本机缺的 LUT 可补，但滤镜列表是应用构建的，需另配列表钩子 |
| gamma / isp / face200m / 决策配置 | 11 | 有对应/格式不同 | 格式与 6.020 不同（决策配置无 aiHighPixel） | ❌ |
**结论：6.020.876 相机没有这些目录的读取逻辑，"挂载补全"对它们无效。**
真正可挂载补全的前提 = 相机已有读取逻辑但文件缺失——本机 odm 是完整的（787 文件），**不缺文件，缺的是功能代码（6.020 比 7.006 少）**。
→ 补全路线仅剩：meishe_lut 增补 + 滤镜列表钩子（组合实现新滤镜条目），列为后续项。


| Muse 功能 | 机制 | 6.020.876 证据 | 状态 |
|---|---|---|---|
| 色彩家族/LUT 资产 | bake LUT → 挂 /odm 路径（**资产已就位**：`OmniCam参考/OmniCam-Muse/module/payload/master_color/` 等数据文件可试挂，风险在接入点而非数据） | `12_验证/_证据/odm/camera/basictone/`（LMTLut/SCLut/ODT）、`filters_lut/` 178 个 LUT 存在；但 6.020 的 BasicTone 调用点与 X9U 的 libBasicTonePhotoX9 槽位机制不同 | ⛔ 暂缓（需实机核对 6.020 管线） |
| 决策配置 JSON | 挂 oplus_camera_preview_decision_config | 本机原版在 `02_本机提取/odm_config/`（170KB）；**无 aiHighPixel/25MP 决策条目**（全文检索 0 命中） | ❌ 无该机制可改 |

## 跨版本相机类存在矩阵（6.020.876 / 6.105.9 / 7.006.107 反编译实测）

| 类（OmniCam 钩子目标） | 6.020.876 | 6.105.9 | 7.006.107 | 影响 |
|---|---|---|---|---|
| CameraConfig.h(String,int[]) | ✓ | ✓ | ✓ | 裁剪带读取：**全版本通用** |
| DataManager.c(DataKey)/g(DataKey,V) | ✓ | ✓ | ✓ | 水印/闪光灯隔离：**全版本通用** |
| ql.g.g(IZZ)V（声音管理器） | ✓ | **✗** | ✓ | 静音：6.105.9 不可用（类被挪/重命名） |
| BaseMode.buildStreamSurface | ✓ | ✓ | ✓ | 模式门/会话：**全版本通用** |
| FilterGroupManager | ✓ | ✓ | ✓ | 滤镜扩展：**全版本通用** |
| WatermarkProcessUnit | ✓ | ✓ | ✓ | 水印处理：**全版本通用** |
| Lut3dDataManager | ✓ | ✓ | ✓ | LUT 管理：**全版本通用** |
| ZoomSeekBar | ✓ | ✓ | ✓ | 变焦条：**全版本通用** |
| feature/xpan（模式代码） | 44 smali | 30 smali | 44 smali | X-Pan 模式代码全版本存在（模块启用后生效） |

结论：**除 ql.g（静音）在 6.105.9 缺失外，其余目标类全版本存在**。
OmniCam 钩子的 try-catch 设计保证：目标类不存在的版本该功能静默跳过，不影响其他功能。
