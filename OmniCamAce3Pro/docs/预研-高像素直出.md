# 预研：高像素直出条件放宽

## Muse 机制（X9U）
放宽 25MP 自动切换的照度/ISO/温度/运动条件，提高自动直出触发率（unlock25mp 钩子 + 决策配置）。

## Ace 3 Pro（6.020.876）核对
- `02_本机提取/odm_config/oplus_camera_preview_decision_config.json`（170KB）全文检索：
  **无 aiHighPixel / HighPixel / 50M / high_pixel 条目**。
- smali 检索：`11_反编译` 无 `aiHighPixel` 字符串；高像素为**手动模式**
  （入口见 `smali/com/oplus/camera/entry/CameraEntry.smali`、`CameraInfoCursor$2.smali`）。
- 算法开关配置有 `aiHighPixel` 模式（`02_本机提取/decrypted/oplus_camera_algo_switch_config.json`），
  但那是引擎侧的算法清单，不是自动切换条件。

## 结论
**不适用**。6.020.876 的高像素是手动选择模式，不存在 Muse 所放宽的"自动直出条件"。
若想提高高像素可用性，方向应是"把高像素模式入口常驻/快捷启动"，属 UI 层改动（待需求确认）。
