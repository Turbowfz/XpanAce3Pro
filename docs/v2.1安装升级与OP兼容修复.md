# v2.1 安装升级与 OPCameraPro 兼容修复

日期：2026-11-20。版本：v2.1 / code21；唯一交付文件名：`XpanAce3Pro-v2.1.zip`。

## 范围

只处理安装时旧 Xpan 残留，以及 OPCameraPro 共存（包括滤镜）。不追加机型、ROM、相机或 SDK 限制，不清相机数据或照片，不改 LSPosed 数据库，不动其他模块的开关。C16/C17、默认 8192×3024、仅 1×、水印隔离均保留。

## 安装失败的本地代码证据

用户截图中第三步的“配置或 SDK 校验未通过”是所有 `runtime.sh install` 失败的统一文案，不足以认定是 SDK 问题。当前手机安装日志尚未取得，以下是已确认的代码阻断条件，不冒充该手机的最终日志结论。

1. v2.0 在 KernelSU 父层覆盖下首次安装、跨 boot 或旧实例状态失效时，需要手工 `parent.approval` 才能准备配置；普通管理器安装没有生成它。此前每次重启手动批准再 install 不是成品应有的操作。
2. OP 自动兼容修复在配置和 SDK 检查之后调用；OP 旧 C16 SDK 已生效时会先拒绝安装，无法执行修复。
3. 旧无锁清理任务会阻止安装；跨签名 Hook APK 只尝试 `install -r`，没有自动迁移，错误仍被统称为配置或 SDK 问题。
4. 旧挂载与安装记录需要先按 Xpan 自己的所有权清理，不能直接删除整个状态目录；OP 原件备份也不能随旧状态一起删除。

## v2.1 已实现的本地修复

- 安装入口自动处理旧 Xpan 挂载与失效状态，自动观察当前父层，不再让用户手写批准文件。
- OP 修复前置；需要重启的补全更新先登记安装、保持 `active=0`，重启后仍使用真实 SDK 检查，不能把待生效的补全当成当前已兼容。
- 唯一 Hook 包 `com.xpanport.hook` 遇真实跨证书错误时先保存旧 APK，再迁移安装；其他 PM 错误不泛化成卸载。
- 安装继续显示简洁的 5 步进度；细节和真实错误保留在日志。
- 同一次开机重复刷入、补全已更新但后续 APK 安装失败，以及 service 才更新补全时，均保留本次启动的待重启标记，防止旧 native 尚未退场就启用。

### 清理和恢复边界

- 旧 APK 备份：`/data/adb/xpan-lifecycle/apk-backup/<安装实例>/`；保存 `base.apk`、旧身份和用户清单，不自动删备份。
- OP 原件备份：`/data/adb/xpan-runtime/op-compat-backup/`；同名首份旧件不覆盖，后续不同旧件另存哈希后缀。
- 仅撤销能够从旧 Xpan journal 证明属于自己的挂载；无 journal 的旧静态覆盖、被其他模块覆盖的挂载以及无法证明已退出的旧锁，不盲目拆掉。此类残留尚不保证自动清理成功，应根据真实日志处理；不能称“所有旧残留都已解决”。
- 跨证书迁移仅卸载自己的独立 Hook 包；其本应用私有数据随 Android 完整卸载而移除，系统相机数据、照片和其他应用不动。旧 APK 备份不是整个应用数据备份。

## 滤镜漏项及证据边界

OP 附属模块不仅覆盖两个 JAR，也覆盖 `/odm/lib64/libmsnativefilter.so` 和 `/product/lib64/libMsEffectSdk.so`。本机 C17 滤镜链直接加载 Meishe 库，历史原厂相机 maps 也证明本机存在这两份原厂库。v2.0 的同步没有处理这两个路径。

旧 SDK 字节、旧 native 和不同来源 LUT 混用是应优先修复的候选；现有材料未保留原厂库实物或完整 LUT 清单，因此尚不能证明特定 native ABI／raw LUT 格式差异，也不能宣布已锁定黑屏唯一根因。

- 两条 Meishe 覆盖采用精确、可逆处理，让本机 C17 原厂库在下次开机透出，不修改系统本体。
- 原厂素材同名优先，OP 独有增量保留；v2.0 已隐藏的目录需要按文件迁移，不能整包删除 OP 的额外滤镜。
- 不能用已挂载的 `/odm`、`/product` 内容当原厂：那可能读到 OP 自己。来源应是干净 lower 层或已核对的原厂位置。
- `libBasicTonePhoto.so` 属于另一条影调链，现有原厂对位证据不足，不顺带盲改。
- `qing_tou.bin`、`hu_po.bin` 以及 Portra 的逗号双 LUT 字符串本来就是 C17 的合法语义，不通过强制“原图”或删除所有滤镜冒充兼容。
- OP 还存在旧 `mbIsSupportBlackandwhitePortraPositiveFilterUpdate` 字段与 C17 `sbBlackandwhitePortraPositiveFilterSupport` 的差异；这影响部分额外功能注册，不能当作普通预览黑屏的直接证明。
